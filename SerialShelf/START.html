СериалПолка — лабораторные 1–7

Ignatev Alexey · K4140

Приложение на Swift/SwiftUI для каталога сериалов, личной коллекции, оценок и комментариев. Все версии самостоятельны: папка LabN содержит собственные Sources, Tests, Resources и конфигурацию проекта. Старые StudyNotes в корне репозитория — предыдущая работа; актуальная новая тема находится только в SerialShelf.

Бесплатно, без ключей

TVmaze предоставляет GET-каталог; JSONPlaceholder принимает учебный POST отзыва, не сохраняя ресурс. Постоянная личная коллекция хранится локально в SwiftData. Настройки — UserDefaults. Данные и изображения TVmaze указаны с атрибуцией CC BY-SA и ссылками на источники.

Что внутри каждой лабы

  • Исходники Swift и тесты XCTest.
  • README с запуском и особенностями версии.
  • DEFENSE.html / DEFENSE.md: подробное объяснение каждого файла и вопросы защиты.
  • Видео и VIDEO-TIMELINE.md с реальными таймкодами — в итоговом архиве после записи.

Windows

Распакуйте итоговый архив. HTML открывается браузером, MP4 — обычным проигрывателем, исходники — PyCharm или VS Code. Собрать SwiftUI для iPhone на Windows нельзя: для сборки и запуска использован настоящий облачный Mac с Xcode. Готовый Xcode-проект и simulator-app приложены отдельно после сборки. Ни Appetize, ни платные сервисы не требуются.
