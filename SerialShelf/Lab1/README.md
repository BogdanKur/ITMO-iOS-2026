# Лабораторная 1 — Swift: заказы, геометрия и очередь

**Ignatev Alexey · K4140 · СериалПолка**

В первой работе решены исходные задания на Swift: обработка заказов, структуры Point/Rectangle и собственная очередь с приоритетом. Это независимый консольный модуль; условие преподавателя сохранено.

## Запуск на Mac

Из этой папки: `swift run Lab1Demo`, тесты: `swift test`. Записанный Xcode-проект приложен в облачном артефакте.

## Windows

Откройте исходники в PyCharm/VS Code как папку и смотрите приложенное MP4. Это настоящий iOS-проект: Windows не запускает SwiftUI или iPhone Simulator. Платные эмуляторы и API-ключи не нужны. Для сборки используйте Mac или GitHub Actions в своём форке.
