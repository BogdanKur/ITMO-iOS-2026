# Лабораторная 3: Архитектура MVVM и внедрение зависимостей

Выбрана MVVM. View отвечает за интерфейс, NotesViewModel — за состояние, валидацию и действия, Note — независимая модель. Repository изолирует хранение; Dependency Injection передаёт реализацию через конструктор. Composition root — StudyNotesApp. Протокол позволяет подменить репозиторий в XCTest.

Четыре экрана: список, детали, создание/редактирование, настройки. Хранение на этом этапе в памяти — после закрытия данные исчезают; постоянное хранение добавляется в лабораторной 4.

На защите: создай заметку, открой детали, измени её, удали свайпом, открой настройки. Покажи направление зависимости View → ViewModel → NoteRepository и MemoryNoteRepository. Объясни, почему View не обращается к базе и почему ViewModel не зависит от SwiftUI. @MainActor сериализует изменения UI-состояния. В тестах есть успешный CRUD, неверное название и ошибки репозитория.

## Запуск и проверка

На Mac: `brew install xcodegen`, затем из этой папки `xcodegen generate`, открой `StudyNotes.xcodeproj`, выбери iPhone Simulator и нажми Run. Test: Product → Test (Cmd+U). Для физического iPhone включи подпись и выбери свой Team: в учебной конфигурации CODE_SIGNING_ALLOWED=NO для облачного симулятора.

На Windows смотри инструкцию [WINDOWS.md](WINDOWS.md). Автоматическая проверка — workflow **Lab 3** в Actions форка. Workflow собирает код и запускает XCTest; статус нужно смотреть в конкретном запуске. Наличие тестов в PR само по себе не означает, что они прошли.

Каждая лабораторная самостоятельна: checkout ветки `codex/lab-3` содержит весь нужный для неё код, другие лабораторные не требуются. Лабораторные 7–8 не изменены: их задания не предоставлены.
