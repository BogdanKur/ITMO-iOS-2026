# Итоговый проект — StudyNotes

Полный проект находится в [Lab6](../Lab6). Исходники: [Lab6/Sources](../Lab6/Sources). Команда `xcodegen generate` в Lab6 создаёт StudyNotes.xcodeproj. Готовый Xcode-проект и архив iOS Simulator выдаёт workflow Lab 6.

SwiftUI, iOS 17+, MVVM, Repository, DI, SwiftData, UserDefaults, фоновые поиск/статистика, Alamofire GET/POST, XCTest. Список, детали, редактор, настройки, анализ, лента, детали публикации — семь представлений.

[Сценарий защиты и объяснение решений](../Lab6/README.md) · [Просмотр на Windows](../Lab6/WINDOWS.md).

Версия для лабораторной 7 находится в [Lab7](../Lab7): те же функции приложения, **три unit-теста NotesViewModel и два независимых UI-сценария**. [Таблица тестов и пояснения для защиты](../Lab7/README.md) · [Результаты тестирования на Windows без Appetize](../Lab7/WINDOWS.md).
