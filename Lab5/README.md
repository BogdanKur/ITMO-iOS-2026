# Лабораторная 5: Фоновый поиск и расчёт статистики

Два места использования многопоточности: поиск по заголовкам/тексту и подсчёт статистики (заметки, слова, символы). Каждая операция запускается в отдельном Task.detached. Поиск имеет приоритет userInitiated, статистика — utility. Они получают копии [Note], соответствующие Sendable; ModelContext и SwiftUI-состояние в фон не передаются.

SwiftUI .task(id:) перезапускает поиск при изменении запроса/заметок. withTaskCancellationHandler отменяет дочернюю detached-задачу. Task.checkCancellation проверяет отмену в цикле и перед публикацией результата. Результат после await присваивается внутри @MainActor ViewModel. Индикаторы загрузки отображаются независимо. На маленьком наборе вычисления могут завершаться почти мгновенно.

На защите: добавь несколько заметок, открой «Анализ», проверь число слов и поиск по разному регистру. Покажи два Task.detached, cancellation handler и MainActor. Объясни, что async сам по себе не гарантирует уход CPU-вычислений с главного актора. Тесты проверяют поиск, статистику, отмену и получение результатов ViewModel.

## Запуск и проверка

На Mac: `brew install xcodegen`, затем из этой папки `xcodegen generate`, открой `StudyNotes.xcodeproj`, выбери iPhone Simulator и нажми Run. Test: Product → Test (Cmd+U). Для физического iPhone включи подпись и выбери свой Team: в учебной конфигурации CODE_SIGNING_ALLOWED=NO для облачного симулятора.

На Windows смотри инструкцию [WINDOWS.md](WINDOWS.md). Автоматическая проверка — workflow **Lab 5** в Actions форка. Workflow собирает код и запускает XCTest; статус нужно смотреть в конкретном запуске. Наличие тестов в PR само по себе не означает, что они прошли.

Каждая лабораторная самостоятельна: checkout ветки `codex/lab-5` содержит весь нужный для неё код, другие лабораторные не требуются. Лабораторные 7–8 не изменены: их задания не предоставлены.
