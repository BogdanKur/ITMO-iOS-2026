# Лабораторная 2: SwiftUI: два экрана и навигация

Первый экран содержит label, кнопку генерации числа 1…100 и кнопку перехода. Второй отображает переданное число; кнопка «Назад» возвращает на первый. Значение хранится в @State и сохраняется при возврате в рамках текущего запуска.

На защите: запусти приложение, несколько раз нажми «Случайное число», открой второй экран и вернись. Объясни: SwiftUI перестраивает представление при изменении @State; NavigationStack управляет стеком, NavigationLink добавляет второй экран. Проверка генератора не требует конкретного случайного числа, проверяет диапазон.

## Запуск и проверка

На Mac: `brew install xcodegen`, затем из этой папки `xcodegen generate`, открой `StudyNotes.xcodeproj`, выбери iPhone Simulator и нажми Run. Test: Product → Test (Cmd+U). Для физического iPhone включи подпись и выбери свой Team: в учебной конфигурации CODE_SIGNING_ALLOWED=NO для облачного симулятора.

На Windows смотри инструкцию [WINDOWS.md](WINDOWS.md). Автоматическая проверка — workflow **Lab 2** в Actions форка. Workflow собирает код и запускает XCTest; статус нужно смотреть в конкретном запуске. Наличие тестов в PR само по себе не означает, что они прошли.

Каждая лабораторная самостоятельна: checkout ветки `lab-2` содержит весь нужный для неё код, другие лабораторные не требуются. Лабораторные 7–8 не изменены: их задания не предоставлены.
