# Лабораторная 4: SwiftData, UserDefaults и CRUD

Использованы два инструмента: SwiftData для структурированных заметок (UUID, название, текст, даты) и UserDefaults для простой настройки сортировки. SwiftData хранит локальные записи в постоянном контейнере; UserDefaults не используется как база заметок.

CRUD: создание через +, чтение списка/деталей, изменение через кнопку в деталях, удаление свайпом. ModelContext.save вызывается явно, при ошибке выполняется rollback и показывается сообщение. Ошибка открытия контейнера показывается отдельно: приложение не подменяет постоянное хранилище временным без уведомления.

На защите: создай две заметки, измени одну, перезапусти приложение и проверь сохранение. Переключи «Сначала новые», перезапусти и проверь настройку, затем удали заметку. Покажи @Model и @Attribute(.unique). Объясни отличие схемы данных от value-модели Note. XCTest проверяет CRUD в изолированном in-memory контейнере и восстановление UserDefaults с отдельным suite.

## Запуск и проверка

На Mac: `brew install xcodegen`, затем из этой папки `xcodegen generate`, открой `StudyNotes.xcodeproj`, выбери iPhone Simulator и нажми Run. Test: Product → Test (Cmd+U). Для физического iPhone включи подпись и выбери свой Team: в учебной конфигурации CODE_SIGNING_ALLOWED=NO для облачного симулятора.

На Windows смотри инструкцию [WINDOWS.md](WINDOWS.md). Автоматическая проверка — workflow **Lab 4** в Actions форка. Workflow собирает код и запускает XCTest; статус нужно смотреть в конкретном запуске. Наличие тестов в PR само по себе не означает, что они прошли.

Каждая лабораторная самостоятельна: checkout ветки `codex/lab-4` содержит весь нужный для неё код, другие лабораторные не требуются. Лабораторные 7–8 не изменены: их задания не предоставлены.
